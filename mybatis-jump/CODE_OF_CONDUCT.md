# 行为准则

## 我们的承诺

为了营造开放、友善和有建设性的社区环境，项目参与者应尊重不同背景、经验水平和观点的贡献者。

## 应有的行为

- 使用友善、尊重和包容的语言。
- 提供具体、可验证和有帮助的反馈。
- 接受不同意见，优先讨论问题本身。
- 对项目和社区承担适当责任。

## 不可接受的行为

- 人身攻击、骚扰、歧视或贬损性言论。
- 发布他人的私人信息。
- 威胁、恶意跟踪或其他不当行为。
- 任何不适合开源协作环境的行为。

## 问题反馈

如果发现违反行为准则的情况，请通过项目仓库的 Issue 或维护者提供的联系方式进行反馈。请尽可能提供时间、地点、相关内容和必要的上下文，并避免公开传播敏感信息。

本项目同时参考 JetBrains 开源与社区行为准则：

[JetBrains 开源与社区行为准则](https://confluence.jetbrains.com/display/ALL/JetBrains+Open+Source+and+Community+Code+of+Conduct)
